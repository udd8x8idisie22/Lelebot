# بوت النشر التلقائي لتيليجرام

## المتطلبات
- Python 3.10 أو أحدث.
- إنشاء بوت عبر @BotFather.
- إضافة البوت إلى القروب المستهدف ومنحه صلاحية إرسال الرسائل.
- معرفة Chat ID للقروب ورقم Telegram User ID للحسابات المسموح لها بالنشر الفوري.

## الإعداد
1. فك ضغط المشروع.
2. انسخ `.env.example` وسمّ النسخة `.env`.
3. افتح `.env` وضع:
   - `BOT_TOKEN`: توكن البوت.
   - `TARGET_CHAT_ID`: معرّف القروب، وغالبًا يبدأ بـ `-100`.
   - `ADMIN_USER_IDS`: أرقام حسابات المشرفين المسموح لهم بأمر `/post`.
   - `POST_INTERVAL_SECONDS`: اتركه `3600` للنشر كل ساعة.

## التشغيل
داخل مجلد المشروع نفّذ:

```bash
python -m venv .venv
```

Windows:
```bash
.venv\\Scripts\\activate
```

Linux / macOS:
```bash
source .venv/bin/activate
```

ثم:
```bash
pip install -r requirements.txt
python main.py
```

سيبدأ أول نشر تلقائي بعد مرور ساعة كاملة من تشغيل البوت، ثم كل ساعة. استخدم `/post` داخل القروب المحدد للنشر الفوري.

## الإيموجيات المخصصة
البرنامج يتعرف على كل رقم مكتوب بين قوسين في نص الإعلان، ويحوّله إلى Telegram `custom_emoji` entity باستخدام المعرّف نفسه. لا يُرسل الرقم كنص ظاهر. يجب أن تكون IDs صحيحة ومتاحة للبوت/الحساب في سياق Telegram؛ ظهور الإيموجي النهائي يعتمد على قبول Telegram للمعرّف.

## ملاحظات الاستقرار والصلاحيات
- النشر مقيّد بـ `TARGET_CHAT_ID`.
- أمر `/post` مقيّد بأرقام `ADMIN_USER_IDS`.
- لا توجد إعادة محاولة تلقائية بعد فشل الإرسال؛ لأن انقطاع الاتصال قد يحدث بعد قبول تيليجرام للرسالة، وإعادة المحاولة حينها قد تسبب تكرارًا.
- راجع سجل الطرفية عند حدوث خطأ.
- لا تشارك ملف `.env` أو التوكن مع أي شخص.
- لا يمكن ضمان اختبار الإرسال الفعلي أو ظهور الإيموجيات دون توكن حقيقي وقروب تجريبي. يمكن التحقق من بناء النص والكيانات محليًا قبل التشغيل.
